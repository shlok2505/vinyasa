# Vinyasa

> Design spaces, intelligently.

Vinyasa is an intelligent spatial understanding system for detecting,
reconstructing, and reasoning about physical spaces.

## Project Structure

- `app/` — Mobile application
- `backend/` — Backend and API
- `vsm/` — Vinyasa Spatial Model
- `experiments/` — Computer vision and 3D experiments
- `docs/` — Project documentation and research
- `data/` — Test and sample data
